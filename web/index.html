FOMO Federated Open Manufacturing Ontologies

FOMO gives manufacturing software a shared vocabulary. It is a network of open ontologies built around one core manufacturing ontology, which follows ISA-95 to describe resources and operations. If two systems use the same terms, you can move data between them and reason over a whole process without writing a new mapping for every tool.

The network is federated: every ontology is a separate module with its own URI and a named maintainer, and they all connect through the core. It is also open. You can reuse and extend any of it under CC BY 4.0.

FlandersMake@UGent – ISyE, a Flanders Make core lab at Ghent University, develops the FOMO architecture and maintains the core ontology.
