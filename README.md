# FOMO: Federated Open Manufacturing Ontologies

_A modular ontology network for manufacturing_

FOMO gives manufacturing software a **shared vocabulary**. It is a network of open ontologies built around one core [manufacturing ontology](https://w3id.org/fomo/manufacturing), which follows **ISA-95** to describe resources and operations. If two systems use the same terms, you can move data between them and reason over a whole process without writing a new mapping for every tool.

Website: <https://w3id.org/fomo>
